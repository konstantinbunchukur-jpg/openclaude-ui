# Безопасность

Это локальный прототип, не сервер для публичного доступа и не песочница.
**Исправлена только защита API от чужих страниц (Host/Origin/тип тела); остальные известные проблемы открыты** — см. [аудит](docs/REVIEW.md).
Привязка к `127.0.0.1` сама по себе не защищает API от запросов чужих веб-страниц.
Проверка на секреты и персональные данные и границы публикации — в
[SECRETS-AUDIT.md](docs/SECRETS-AUDIT.md).

- Не публикуйте порт через туннель, прокси или LAN.
- Не работайте с единственной копией важных файлов: используйте Git и резервные копии.
- `config.json` содержит ключи API в открытом виде; API `/api/state` также возвращает их UI.
  Не прикладывайте конфигурацию, историю чатов и непроверенные скриншоты к issue.
- Настройки CLI и рабочие папки должны быть доверенными. CLI выполняется с правами пользователя.
- До устранения P0 из `docs/REVIEW.md` не объявляйте эту версию безопасным стабильным релизом.

## Проверки

`npm test` проверяет основные сценарии с фиктивным CLI, а не безопасность.
`npm run test:security` проверяет необходимые защитные свойства и сейчас завершается ошибкой.
Оба набора используют одноразовую копию сервера и синтетические данные без реальных ключей.

## Сообщение об уязвимости

После размещения на GitHub включите Private vulnerability reporting в настройках
репозитория. Если эта возможность доступна, используйте вкладку Security → Report a
vulnerability. Не публикуйте действующие ключи и персональные данные. Если приватный
канал ещё не настроен, запросите его у владельца без раскрытия деталей эксплуатации.
