# OpenClaude UI — простой оконный интерфейс для openclaude

> **Неофициальный проект.** Сторонний интерфейс к CLI
> [openclaude](https://github.com/Twigpine/openclaude): не связан с авторами
> openclaude и не поддерживается ими. Название описывает совместимость, а не
> происхождение. Код openclaude в проект не входит — интерфейс запускает
> установленный у вас CLI.

> **Статус: локальный прототип.** API уже отклоняет запросы чужих страниц, но
> остаются неисправленные проблемы запуска CLI и сохранности файлов. Перед использованием прочитайте
> [SECURITY.md](SECURITY.md) и [обзор с приоритетами](docs/REVIEW.md).
> Не открывайте сервер в интернет и не работайте с единственной копией важных данных.
>
> [Разработка и проверки](#разработка-и-проверки) · [Аудит данных](docs/SECRETS-AUDIT.md) · [Подготовка GitHub](docs/PUBLISH.md)

Это **локальный веб-интерфейс** (чат в браузере) для консольного агента
[openclaude](https://github.com/Twigpine/openclaude). Он делает то же, что и
терминал, но в привычном виде: пишете задачу — агент читает файлы, правит код,
запускает команды, а вы видите каждый его шаг.

Работает на Windows 10/11, **не требует ничего компилировать и не ставит
зависимостей** — нужен только установленный Node.js.

---

## Быстрый старт (3 шага)

1. **Установите Node.js** (если ещё нет): https://nodejs.org/ — версия LTS или новее.
   openclaude требует Node.js **22 или новее**.
2. **Запустите `start-ui.bat`** двойным кликом — откроется браузер с интерфейсом
   (`http://127.0.0.1:8321`).
3. **Настройте** (кнопка ☰ слева сверху):
   - **Рабочая папка** — папка вашего проекта (можно создать прямо там);
   - **Провайдер и модель** — выберите готовый набор (OpenAI / Ollama / Gemini)
     и вставьте ключ API;
   - нажмите **«Сохранить настройки»**.

Готово — пишите задачу в чат.

> Если openclaude ещё не установлен, интерфейс сам предложит кнопку
> «Установить сейчас» (выполнит `npm install -g @twigpine/openclaude@latest`).

## Что где находится

| Элемент | Зачем |
|---|---|
| ☰ | Открыть/закрыть панель настроек |
| 📁 чип сверху | Текущая рабочая папка (клик — открыть настройки) |
| «＋ Новый чат» | Начать разговор заново (старая сессия отвязывается) |
| 🔧 оранжевые плашки | Шаги агента: какую команду/файл он обработал. Клик — раскрыть подробности |
| «Журнал» внизу | Технический вывод CLI (ошибки, предупреждения) |
| ■ Стоп | Прервать работу агента |

### Настройки (☰)

- **Программа openclaude** — команда запуска CLI. По умолчанию `openclaude`
  (ищется в PATH). Можно указать полный путь к `openclaude.cmd`.
- **Рабочая папка** — с ней агент будет работать. Кнопки: создать папку,
  открыть в Проводнике, открыть Терминал. В «Дополнительных папках доступа»
  можно перечислить папки вне рабочей (`--add-dir`).
- **Провайдер и ключ API** — готовые наборы:
  - **OpenAI** — ключ с platform.openai.com;
  - **Ollama (локально)** — бесплатно, без ключа: установите
    [Ollama](https://ollama.com), выполните `ollama pull qwen2.5-coder:7b`;
  - **Gemini** — ключ с aistudio.google.com/apikey;
  - **Другой OpenAI-совместимый API** — свой адрес/ключ/модель;
  - список переменных можно править вручную (двойной клик по полю пароля
    показывает значение);
  - **«Проверить соединение»** — отправляет один короткий тестовый запрос
    через текущие настройки и показывает, отвечает ли API. Ничего
    разворачивать не нужно: ключ передаётся прямо в CLI на вашем компьютере.
- **Модель** — название модели (`--model`: gpt-4o, sonnet, qwen2.5-coder:7b …),
  резервная модель на случай перегрузки (`--fallback-model`) и «усердие»
  (`--effort`: от low до ultracode).
- **Инструкции агенту** — постоянные правила, добавляемые к системному промпту
  (`--append-system-prompt-file`): «отвечай по-русски», «сначала план» и т.п.
- **Права агента**:
  - *Только план* (`plan`) — агент изучает проект и описывает, что сделал бы,
    но ничего не меняет; лучший выбор для первых задач;
  - *Спрашивать* — в чате подтверждения недоступны, поэтому «опасные» шаги
    агент пропустит;
  - *Только разрешённое* (`dontAsk`) — агент выполняет только инструменты из
    списка «Разрешить», остальное запрещено без вопросов;
  - *Принимать правки* (по умолчанию) — агент может править файлы; команды
    разрешаются списком `--allowedTools` (например `Bash(git:*),Read,Edit`);
  - *Без ограничений (опасно)* — соответствует `--dangerously-skip-permissions`.
  - Дополнительно: списки разрешённых и запрещённых инструментов и готовые
    наборы для них («Только чтение», «Правки и git», «Правки, git и npm»).
- **Лимиты** — максимум шагов агента и максимальный расход в USD на один
  запрос (`--max-turns`, `--max-budget-usd`).

### Кнопки сверху

- **▶ Продолжить** — подхватить самый свежий чат текущей папки (`--continue`/`--resume`).
- **🕘 История** — все прошлые чаты (как их хранит сам openclaude в `~/.openclaude`);
  любой можно продолжить или создать его копию-ответвление (`--fork-session`).
- **＋ Новый чат** — начать заново, старые чаты остаются в Истории.
- **❓ (F1)** — встроенная справка: быстрый старт, значение каждой кнопки и FAQ.
- **EN / RU** — язык интерфейса (English / русский). По умолчанию берётся язык
  браузера, выбор запоминается.

При первом запуске открывается приветствие с четырьмя шагами: установить CLI,
подключить модель, выбрать папку и проверить соединение, начать безопасно
(копия проекта или коммит в Git, режим «Только план»).

### Покрытие возможностей CLI

| Возможность CLI | Как в UI |
|---|---|
| `-p --output-format stream-json` | каждый запрос чата |
| `--resume` / `--continue` / `--fork-session` | автопродолжение, «▶ Продолжить», «🕘 История» |
| `--model`, `--fallback-model`, `--effort` | карточка «Модель» |
| `--append-system-prompt` | «Инструкции агенту» |
| `--permission-mode`, `--allowedTools`, `--disallowedTools` | «Права агента» |
| `--add-dir`, `--mcp-config` | доп. папки, MCP-конфиги (в «Дополнительно») |
| `--max-turns`, `--max-budget-usd` | «Лимиты» |
| `--provider` + ключи через env | «Провайдер и ключ API» + проверка соединения |
| `npm i -g @twigpine/openclaude` | кнопка установки в приветствии |

Остальное (редкие сценарии) — в терминале, кнопка «Терминал» открывает его
сразу в рабочей папке: фоновые сессии (`--bg`, `ps`, `logs`, `kill`),
`auth`/`setup-token`, `doctor`, управление `mcp`/`plugin`/`skills`.

## Как это работает

На каждый запрос интерфейс запускает CLI в headless-режиме в выбранной папке:

```
openclaude --print --output-format stream-json --verbose [--resume <сессия>] [прочие флаги] < сообщение.txt
```

Ответ приходит построчно в JSON и рисуется в чате. После первого ответа
запоминается `session_id`, и следующие сообщения в той же папке
автоматически продолжают ту же сессию (`--resume`). Кнопка «＋ Новый чат»
отвязывает сессию.

Настройки хранятся рядом в `config.json`, диалоги сессий — там же, где их
хранит сам openclaude (в домашней папке пользователя).

## Частые проблемы

- **«openclaude не найден»** — установите: `npm install -g @twigpine/openclaude@latest`,
  затем нажмите «Проверить ещё раз». Либо укажите полный путь к `openclaude.cmd`
  в настройках.
- **«Node.js не найден» при запуске bat** — установите Node.js с nodejs.org и
  запустите bat заново.
- **Порт 8321 занят** — интерфейс сам попробует соседние порты и покажет
  фактический адрес в окне консоли.
- **Предупреждение «Настройки CLI не найдены»** — у openclaude нет файла
  `~/.openclaude.json`. Можно нажать кнопку восстановления из резервной копии
  (если есть `.claude.json.backup`) или задать провайдера ключом в настройках UI.
- **Агент «не может» выполнить команду** — в режиме «Принимать правки»
  разрешайте нужные команды через `--allowedTools`, либо включите режим
  «Без ограничений» (осознанно и только в доверенных папках).
- **Изменились ключи/модель** — правьте их в настройках (☰) и сохраняйте;
  перезапуск не нужен.

## Безопасность

- Сервер слушает только `127.0.0.1` — доступ с этого компьютера.
- `config.json` содержит ключи API — **не выкладывайте его** в интернет
  (он добавлен в `.gitignore`).
- Агент по вашей задаче читает и меняет файлы в рабочей папке и может
  выполнять команды. Держите включёнными лимиты и осмотрительно выбирайте
  режим прав.

## Разработка и проверки

Нужен Node.js 22+. `npm install` не требуется — внешних зависимостей нет.
Основная платформа — Windows; функции Проводника/Терминала зависят от неё.

```sh
npm start              # то же, что node server.js
npm run check          # проверка синтаксиса
npm test               # smoke: API, mock CLI, SSE, файлы и история
npm run test:security  # проверки защитных свойств; сейчас выявляют известные дефекты
```

Тесты создают одноразовую копию приложения с отдельными настройками, файлами и
историей. Реальный CLI, ключи API и сеть провайдера не используются. Windows CI
проверяет Node.js 22/24; security-задача остаётся красной до устранения дефектов.

Для ручной настройки можно скопировать `config.example.json` в `config.json`
**только если своего файла ещё нет**. Пример задаёт режим `default`, 10 шагов и
лимит $1; встроенные настройки приложения без этого примера остаются прежними.

### Связь с проектом openclaude

Это самостоятельный проект, а не форк репозитория openclaude: общего кода нет,
интерфейс только вызывает установленный CLI через штатные флаги. Поэтому на
GitHub он и не помечается как форк — баннер «forked from» появляется только у
настоящих форков. Совместимость и происхождение указаны в начале README, в поле
About и в topics репозитория.
