  1. Установить openclaude — проверяю…
        
    
          npm install -g @twigpine/openclaude@latest
          
        
    
        
    
      
    2. 
      
  2. Подключить модель — ключ API провайдера (OpenAI, Gemini) или бесплатная локальная Ollama. Всё задаётся в настройках (кнопка ☰ слева сверху).
    3. 
      
  3. Выбрать рабочую папку и нажать «Проверить соединение» в тех же настройках, затем «Сохранить настройки».

Как начать

    
    
      
  1. Нажмите ☰ → «Рабочая папка» — укажите папку проекта (или создайте новую кнопкой рядом).
    2. 
      
  2. Там же → «Провайдер и ключ API»: выберите набор (OpenAI / Ollama / Gemini), вставьте ключ. Нажмите «Проверить соединение» — должно появиться зелёное «работает».
    3. 
      
  3. Сохранить настройки → пишите задачу в поле снизу. Всё.
    4. 
    


    
Кнопки сверху

    
    
      
  • 📁 папка — с ней работает агент; клик открывает настройки.
    • 
      
  • ▶ Продолжить — подхватить самый свежий чат этой папки.
    • 
      
  • 🕘 История — все прошлые чаты (любых папок), можно продолжить любой или его копию.
    • 
      
  • ＋ Новый чат — начать с чистого листа (старые чаты остаются в Истории).
    • 
      
  • ❓ — эта справка.
    • 
      
  • EN / RU — язык интерфейса.

Что значат плашки в чате

    
    
      
  • 🔧 оранжевые — агент что-то делает: команда, чтение/правка файла. Клик раскрывает подробности; ✓ — шаг завершён.
    • 
      
  • ■ Стоп — прервать работу немедленно.
    • 
      
  • Журнал внизу — технический вывод CLI (нужен при ошибках).

Полезные настройки (☰)

    
    
      
  • Модель — например gpt-4o, sonnet или qwen2.5-coder:7b для Ollama; «усердие» — глубина продумывания.
    • 
      
  • Инструкции агенту — постоянные правила («отвечай по-русски», «сначала план»).
    • 
      
  • Права — начните с «Только план»: агент ничего не меняет, только описывает план. Затем «Принимать правки» — подходит большинству; «Без ограничений» — только в доверенных папках. Перед правками делайте копию проекта или коммит в Git.
    • 
      
  • Лимиты — максимум шагов и расходы в USD на один запрос.
    • 
    


    
Частые вопросы

    
    
      
  • «Агент не вошёл в систему» / «Not logged in»? Нажмите «🔐 Войти через аккаунт Claude» в сообщении об ошибке или в жёлтой плашке сверху — откроется страница входа в браузере. Либо задайте ключ API провайдера в настройках (☰).
    • 
      
  • Слэш-команды терминала (/provider и т.п.)? Они работают в терминале; их функции уже вынесены в кнопки настроек. Кнопка «Терминал» в настройках открывает консоль в рабочей папке.
    • 
      
  • Нужен ли отдельный сервер? Нет: ключ API из настроек передаётся прямо в CLI на вашем компьютере, ничего разворачивать не нужно.
    • 
      
  • Где хранятся данные? Настройки — в config.json рядом с программой; чаты — в домашней папке (~/.openclaude), как у терминального openclaude. Ключи никуда не отправляются, кроме провайдера.
    • 
      
  • «openclaude не найден» — установите его кнопкой в приветствии или npm install -g @twigpine/openclaude@latest.
    • 
      
  • Фоновые задачи, вход в аккаунт, doctor — эти редкие команды пока только в терминале (кнопка «Терминал»).

Getting started

    
    
      
  1. Click ☰ → “Workspace folder” and enter your project folder (or create a new one with the button next to it).
    2. 
      
  2. In the same panel → “Provider and API key”: pick a preset (OpenAI / Ollama / Gemini) and paste the key. Click “Test connection” — you should see a green “works”.
    3. 
      
  3. Save settings, then type a task in the box at the bottom. That’s it.
    4. 
    


    
Top bar buttons

    
    
      
  • 📁 folder — the folder the agent works in; click to open settings.
    • 
      
  • ▶ Continue — pick up the latest chat in this folder.
    • 
      
  • 🕘 History — all past chats (any folder); continue any of them or a copy.
    • 
      
  • ＋ New chat — start from scratch (old chats stay in History).
    • 
      
  • ❓ — this help.
    • 
      
  • EN / RU — interface language.
    • 
    


    
What the chat badges mean

    
    
      
  • 🔧 orange — the agent is doing something: a command, reading or editing a file. Click to expand; ✓ — step finished.
    • 
      
  • ■ Stop — interrupt immediately.
    • 
      
  • Log at the bottom — technical CLI output (useful for errors).
    • 
    


    
Useful settings (☰)

    
    
      
  • Model — e.g. gpt-4o, sonnet, or qwen2.5-coder:7b for Ollama; “effort” is how deeply the agent thinks.
    • 
      
  • Agent instructions — standing rules (“reply in English”, “show a plan first”).
    • 
      
  • Permissions — start with “Plan only”: the agent changes nothing and only describes a plan. Then “Accept edits” suits most people; “No restrictions” only in trusted folders. Make a copy of the project or a Git commit before edits.
    • 
      
  • Limits — maximum steps and USD spend per request.
    • 
    


    
FAQ

    
    
      
  • “Agent is not logged in” / “Not logged in”? Click “🔐 Sign in with Claude account” in the error message or the yellow banner — a sign-in page opens in the browser. Or set a provider API key in settings (☰).
    • 
      
  • Terminal slash commands (/provider etc.)? They work in the terminal; their functions are already available as settings. The “Terminal” button opens a console in the workspace folder.
    • 
      
  • Do I need a separate server? No: the API key from settings is passed straight to the CLI on your computer.
    • 
      
  • Where is data stored? Settings — in config.json next to the program; chats — in your home folder (~/.openclaude), like the terminal openclaude. Keys are sent only to the provider.
    • 
      
  • “openclaude not found” — install it with the button in the welcome window or npm install -g @twigpine/openclaude@latest.
    • 
      
  • Background tasks, doctor, plugins — these rare commands are terminal-only for now (“Terminal” button).
