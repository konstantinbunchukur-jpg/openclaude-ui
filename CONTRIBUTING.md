# Как помочь проекту

Это локальный прототип: сначала прочитайте [ограничения безопасности](SECURITY.md)
и [план улучшений](docs/REVIEW.md).

## Issues

- Ошибки и предложения — через [шаблон issue](https://github.com/konstantinbunchukur-jpg/openclaude-ui/issues/new/choose).
- Уязвимости — **не** в публичных issues: см. [SECURITY.md](SECURITY.md).
- Не прикладывайте `config.json`, ключи API, историю чатов и скриншоты с реальными
  путями и именами: замените их синтетическими данными.

## Pull requests

- Одна логическая правка на PR, короткое описание и причина изменения.
- Перед отправкой запустите:

  ```sh
  npm run check
  npm test
  ```

- Не ослабляйте `npm run test:security` (`skip`, `todo`, `continue-on-error`,
  ослабленные assertions): исправление готово, когда соответствующая проверка
  зелёная.
- Стиль: без внешних зависимостей, ванильный JS, Node.js 22+, основная платформа —
  Windows. Новые провайдеры и сложный Markdown — после исправления P0.

## Лицензия вклада

Отправляя PR, вы соглашаетесь распространять свой вклад на условиях
[лицензии MIT](LICENSE).
